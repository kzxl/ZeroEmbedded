# ZeroEmbedded Directives
- Maintain zero runtime overhead (no GC, no VM, no required heap).
- Enforce Rule 1-4: C compatibility layer, Rust safety island, zero-cost first, C ABI boundary.
- All new memory primitives must be verified with compile-time assertions and benchmarks.
- Comply strictly with R_EMBEDDED: zero dynamic heap in hot loops and ISR, non-blocking calls, and -Werror discipline.
- Comply strictly with R_BENCH: log hardware execution environment provenance (HEPM) at benchmark runner startup.
